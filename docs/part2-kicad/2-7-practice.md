# 2-7 練習：LED 基板を最後まで作る

## ねらい

- 回路図から製造データまで、一人で通して作れる

この章は [ハンズオン H1](../handson/h1.md) と同じ内容です。H1 では、チェックリストと合格条件つきで進められます。

## 作るもの

![H1 の基板（表）](../assets/boards/h1-led-front.svg){ .board width="420" }

- 電池（XH 2P）→ 逆接続保護のショットキーダイオード → スイッチ → 抵抗 → LED（赤・緑）
- 大きさ 45 × 25 mm、M3 の穴 2 つ
- 裏面は全面 GND

## 進め方

1. [2-1](2-1-project.md) のとおりにプロジェクト `my-led` を作る
2. [2-2](2-2-schematic.md) のとおりに回路図を描き、ERC のエラーを 0 にする
3. [2-3](2-3-footprint.md) の表のとおりにフットプリントを割り当てる
4. [2-4](2-4-layout.md) のとおりに、外形・配置・配線・ベタ GND を作る
5. [2-5](2-5-drc.md) のとおりにルールを入れ、DRC のエラーを 0 にする
6. [2-6](2-6-output.md) のとおりに 3D で確かめ、ガーバーを出す

## 答え合わせ

完成したら、教材の `kicad/h1-led/` と比べてください。部品の位置や配線は同じでなくてかまいません。

- ネット（どのピンとどのピンがつながっているか）は同じか
- 電源の配線（VIN_RAW、VIN、VSW）が信号より太いか
- LED の向き（カソードが GND 側）が合っているか
