# 4-3 リセット・ブート・書き込み

## ねらい

- マイコンにプログラムを書きこむ方法を説明できる
- 基板に載せた後でも書きこめるように、配置を考えられる

## 書きこみの方法

| 方法 | 使うマイコン | 必要なもの |
|---|---|---|
| USB（ブートローダ） | Arduino Nano、ESP32、RP2040 など | USB ケーブル。開発ボードなら USB コネクタ付き |
| UART | ESP32、STM32 の一部 | USB-シリアル変換、ブートモードに入れる操作 |
| SWD・JTAG | STM32、RP2040 | ST-LINK などの書き込み器と、4〜5 本の端子 |
| ISP | ATmega328P | AVR 書き込み器 |

開発ボードを載せる教材のメイン基板では、**ボードの USB コネクタ**から書きこみます。

!!! warning "USB コネクタは外から挿せる向きに"
    メイン基板では、Nano の USB の向きが基板の右の端になるように置いています。ロボットに組んだ後でもケーブルを挿せることを、3D ビューアと実物で確かめてください。組んだら USB が挿せない、はよくある失敗です。

## リセットとブート

- **リセット**：マイコンを最初から動かしなおす。開発ボードにはボタンがあります。ロボットの外からも押せるように、リセットのピンを外に出すこともあります（教材では出していません）。
- **ブートモード**：ESP32 や RP2040 は、特定のピン（ESP32 の GPIO0、RP2040 の BOOTSEL）を押しながらリセットすると、書きこみを待つ状態になります。**このピンを、ほかの回路で勝手に L にしない**よう注意します。

!!! tip "起動のときに使うピンに注意"
    ESP32 の GPIO0・GPIO45・GPIO46 など（チップによって違う）は、起動時の電圧で動作が変わる「ストラッピングピン」です。プルアップ・プルダウンを付けたり、センサをつないだりすると、起動しなくなることがあります。データシートの「Strapping Pins」を確かめてから使います。

## UART の書きこみとぶつからないように

Arduino Nano の D0（RX）・D1（TX）は、USB の書きこみにも使われます。ここに CoreS3 をつないだまま書きこむと、失敗することがあります。

- 書きこむときは、CoreS3 のケーブルを抜く
- または、ジャンパで切りはなせるようにする

教材のメイン基板では J7 のケーブルを抜けばよいように、コネクタにしています。

## チェック問題

1. ロボットを組み立てた後に USB が挿せないことがわかりました。設計のどこで防げましたか。
2. Nano の D0・D1 を UART に使うとき、書きこみで気をつけることは何ですか。

??? success "答え"
    1. 配置のときに USB の向きを決め、3D ビューア（[2-6](../part2-kicad/2-6-output.md)）で確かめる。
    2. 書きこみの間は、D0・D1 につないだ相手（CoreS3 など）を外す。
