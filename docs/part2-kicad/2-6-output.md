# 2-6 3D 表示と製造データの出力

## ねらい

- 3D ビューアで、部品の向きや当たりを確かめられる
- ガーバー・ドリル・部品表（BOM）を出力できる

## 3D で確かめる

基板エディタで ++alt+3++（「表示 → 3D ビューアー」）を押すと、部品が載った基板が 3D で見られます。

確かめること：

- コネクタの向き（ケーブルが外に出せるか）
- 背の高い部品（電解コンデンサ）が、上の基板やカバーに当たらないか
- 取りつけ穴の近くに部品がないか（ネジの頭が当たる）

「ファイル → エクスポート → STEP」で 3D データを出せば、Fusion などの CAD でロボットの機構と組み合わせて確かめられます。

## 製造データ（ガーバーとドリル）

基板メーカーに送るのは、**ガーバー**（各レイヤーの絵）と**ドリル**（穴の位置）のファイルです。

### 手で出す

1. 基板エディタで「ファイル → 製造用出力 → ガーバー（.gbr）」を開きます。
2. 出力するレイヤーにチェックを入れます：`F.Cu`、`B.Cu`、`F.Paste`、`B.Paste`、`F.Silkscreen`、`B.Silkscreen`、`F.Mask`、`B.Mask`、`Edge.Cuts`。
3. 出力先を `gerbers/` にして「プロット」を押します。
4. 同じ画面の「ドリルファイルを生成」で、ドリルファイルも同じフォルダに出します。
5. `gerbers/` フォルダを zip にまとめます。

### GitHub Actions で出す

このリポジトリでは、push すると Actions がガーバー・ドリル・回路図 PDF・部品表を作ります。

1. GitHub のリポジトリで「Actions」タブを開きます。
2. 一番上の「kicad」の実行を開きます。
3. 下の「Artifacts」から `kicad-outputs` をダウンロードします。

!!! warning "ガーバーはリポジトリに入れない"
    ガーバーは KiCad のデータからいつでも作れるので、リポジトリには入れません（`.gitignore` と「うっかり公開チェック」で止めています）。古いガーバーが残っていて、まちがって発注する事故も防げます。

## 部品表（BOM）

どの部品を何個買うかの一覧です。回路図エディタの「ツール → 部品表を生成」で CSV にできます。

| 列 | 入れておくとよいこと |
|---|---|
| Reference | R1, R2 … |
| Value | 10k、0.1uF … |
| Footprint | 0805 など |
| 型番・購入先 | シンボルのプロパティに「MPN」「Supplier」などのフィールドを足して書いておく |

国際大会では、決まった形式の BOM の提出が求められることがあります（[9-5](../part9-build/9-5-inspection.md)）。

## チェック問題

1. ガーバーを出すときに `Edge.Cuts` を忘れるとどうなりますか。
2. 3D ビューアで確かめるとよいことを 2 つ挙げてください。

??? success "答え"
    1. 基板の外形がわからないので、メーカーが作れない（または外形がおかしくなる）。
    2. コネクタの向き、背の高い部品の当たり、取りつけ穴とネジの当たり（このうち 2 つ）。
