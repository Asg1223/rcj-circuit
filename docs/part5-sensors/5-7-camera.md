# 5-7 カメラやサブ基板とのつなぎ方

## ねらい

- M5Stack CoreS3 などのカメラ付きマイコンと、メイン基板をつなぐ回路を描ける

## つなぎ方の選択肢

| 方法 | 線の数 | 特徴 |
|---|---|---|
| UART | 2 本＋GND | 簡単。双方向。教材のメイン基板 J7 |
| I2C | 2 本＋GND | ほかの I2C 機器と同じ線を使える。速さは遅め |
| SPI | 3〜4 本＋GND | 速い。配線が多い |

教材では UART を使います。[機械学習の教材 第5部](https://asg1223.github.io/rcj-soccer-ml/) の「パケット」（`A5 5A TYPE LEN SEQ PAYLOAD CRC8`）をそのまま流せます。

## 電圧と電源

- CoreS3 の GPIO は **3.3 V**。Nano（5 V）の TX は分圧で下げます（[4-2](../part4-mcu/4-2-level.md)）。
- CoreS3 は自分の電池を持っていますが、ロボットの 5 V から電気を送ることもできます。その場合は、CoreS3 の電源の入れ方（どのピン・端子から入れるか）を、M5Stack の公式ドキュメントで必ず確かめてください。教材のメイン基板の J7 は、信号と GND だけにしています。
- **GND は必ずつなぐ**。信号の基準になります。

## チェック問題

1. メイン基板と CoreS3 を UART でつなぐとき、TX と RX はどうつなぎますか。
2. 信号の線だけつないで、GND をつながないとどうなりますか。

??? success "答え"
    1. メインの TX → CoreS3 の RX、CoreS3 の TX → メインの RX（たすきがけ）。
    2. 電圧の基準がそろわず、通信できない（またはまちがえる）。
