# 5-6 IMU（ジャイロ・加速度）

## ねらい

- IMU を I2C でつなぐ回路（電源・プルアップ・レベル変換）を描ける
- IMU の取りつけ位置の注意を言える

## 理論

IMU（慣性計測装置）は、ジャイロ（回転の速さ）と加速度を測ります。サッカーロボットでは、**ロボットがどの向きを向いているか**（相手ゴールの方向）を知るのに使います。地磁気センサは、モータやソレノイドの磁気で狂いやすいので、ジャイロを中心に使うのが一般的です。

### つなぎ方（I2C）

| 線 | 役割 |
|---|---|
| VCC | 電源（多くは 3.3 V） |
| GND | GND |
| SDA | データ |
| SCL | クロック |

- I2C には**プルアップ抵抗**が必要です（[1-2](../part1-basics/1-2-divider.md)）。モジュールに付いていることも多いので、二重になっていないか確かめます（並列になると抵抗が小さくなる）。
- マイコンが 5 V、IMU が 3.3 V なら、**レベル変換**をします（[4-2](../part4-mcu/4-2-level.md)）。教材のメイン基板の Q1・Q2 です。

## 取りつけ位置

- ロボットの**回転の中心の近く**、水平に
- モータ・ソレノイド・大電流の配線から離す
- 振動の少ないところ（ゴムで浮かせることもある）
- ケーブルが引っぱられないように固定

!!! tip "モジュールのピン順"
    IMU モジュールのピン順は製品ごとに違います。教材のメイン基板 J6 は「+3V3、SCL、SDA、GND」の順にしています（基板の配線の都合）。手持ちのモジュールに合わせてケーブルを作ってください。

## チェック問題

1. IMU モジュールにすでにプルアップ抵抗が付いていて、メイン基板にも付いているとどうなりますか。
2. IMU をソレノイドのすぐ横に付けると、どんな問題が起きますか。

??? success "答え"
    1. 並列になって抵抗が小さくなる。少しなら問題ないが、小さすぎると 0 に引けなくなる。
    2. 磁気や振動で値がおかしくなる（特に地磁気センサ）。
