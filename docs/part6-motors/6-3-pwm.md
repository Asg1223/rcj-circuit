# 6-3 PWM と電流

## ねらい

- PWM でモータの速さを変えるしくみを説明できる
- DRV8871 の電流制限の抵抗を計算できる

## 理論

### PWM

ON と OFF を速くくり返し、ON の時間の割合（**デューティ比**）で、平均の電圧を変えます。

$$
V_{平均} = V_{BAT} \times \text{デューティ比}
$$

Arduino の `analogWrite(pin, 128)` は、デューティ比 約 50 % です。

### PWM の周波数

| 周波数 | 特徴 |
|---|---|
| 低い（数百 Hz） | モータから「キーン」という音。トルクがぎくしゃく |
| 高い（20 kHz 以上） | 音が聞こえない。ドライバの切りかえの熱が増える |

Arduino Nano（ATmega328P）の標準では、D5・D6 が約 980 Hz、D3・D9・D10・D11 が約 490 Hz です。タイマーの設定を変えると高くできます（もっと深く）。

### 電流制限（DRV8871）

ILIM ピンと GND の間の抵抗で、流せる電流の上限を決めます。

$$
I_{TRIP}\,[\text{A}] = \frac{64}{R_{ILIM}\,[\text{k}\Omega]}
$$

| $R_{ILIM}$ | 電流の上限 |
|---|---|
| 15 kΩ（最小） | 約 4.3 A（ただし IC のピークは 3.6 A） |
| 21 kΩ | 約 3.0 A |
| 32 kΩ（教材） | 約 2.0 A |
| 64 kΩ | 約 1.0 A |

上限に達すると、IC が自動で電流を抑えます。モータが押さえつけられても、電流が上限をこえないので、配線・電池・IC を守れます（[計算ツール](../tools/index.md#ilim)）。

!!! tip "電流制限の決め方"
    モータのロック電流より小さく、ふつうに走るときの電流より大きく。電流を小さくしすぎると、加速が弱くなります。実際に押し合いをして決めます。

### 発熱

ドライバ IC の熱は、主に ON のときの抵抗 $R_{DS(on)}$ で決まります。

$$
P \approx I^2 \times (R_{DS(on)}^{上} + R_{DS(on)}^{下})
$$

DRV8871 は上下あわせて約 0.565 Ω（標準）なので、2 A で約 2.3 W。放熱パッドを裏の GND ベタにしっかりつなぎます。

## チェック問題

1. 11.1 V でデューティ比 30 % のとき、モータにかかる平均の電圧は何 V ですか。
2. 電流の上限を 2.5 A にしたい。$R_{ILIM}$ は何 kΩ ですか。

??? success "答え"
    1. 約 3.3 V
    2. 64 / 2.5 = 25.6 kΩ → 近い値の 27 kΩ（上限は約 2.4 A）

??? example "もっと深く：Nano の PWM を 31 kHz にする"
    D9・D10（タイマー1）の分周を 1 にすると、位相補正 PWM で約 31.4 kHz になります。

    ```cpp
    TCCR1B = (TCCR1B & 0b11111000) | 0x01;   // D9・D10 を約 31 kHz に
    ```

    タイマー0（D5・D6）を変えると、`millis()` や `delay()` の時間がずれるので注意します。
