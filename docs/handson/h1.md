# H1 KiCad で LED 基板を作る

**時間の目安：3 時間**　｜　対応：[第2部](../part2-kicad/index.md)

## ステップ

- [ ] KiCad 10 を起動し、新しいプロジェクト `my-led` を作る（[2-1](../part2-kicad/2-1-project.md)）
- [ ] 回路図に J1・D1・SW1・R1・R2・D2・D3・H1・H2 を置く（[2-2](../part2-kicad/2-2-schematic.md)）
- [ ] 線・ラベル・GND でつなぎ、PWR_FLAG を付ける
- [ ] アノテーションして、値を入れる
- [ ] ERC を走らせ、エラーを 0 にする
- [ ] フットプリントを割り当てる（[2-3](../part2-kicad/2-3-footprint.md) の表）
- [ ] ++f8++ で基板に取りこむ
- [ ] 45 × 25 mm の外形（角を丸く）を描く
- [ ] 部品を配置し、配線する（電源 0.6 mm、LED への信号 0.4 mm）
- [ ] 裏に GND のベタを作り、LED のカソードの近くにビアを打つ
- [ ] デザインルール（[2-5](../part2-kicad/2-5-drc.md)）を入れ、DRC のエラー・未接続を 0 にする
- [ ] 3D ビューアで確かめる
- [ ] ガーバーとドリルを出し、ガーバービューアで見る
- [ ] Git でコミットする

## 合格条件

| 項目 | 目安 |
|---|---|
| ERC のエラー | 0 |
| DRC のエラー・未接続 | 0 |
| ネット | 教材の `kicad/h1-led` と同じ 6 本（VIN_RAW・VIN・VSW・LED1_A・LED2_A・GND） |
| 電源の配線 | 0.5 mm 以上 |

## 困ったとき

- **部品が基板に出てこない**：フットプリントを割り当てていない。または ++f8++ をしていない。
- **ラッツネストが消えない**：配線がパッドの中心まで届いていない。++d++ で引きずって直す。
- **ベタが塗られない**：++b++ を押す。ゾーンのネットが GND になっているか確かめる。

## 発展課題

1. LED を 3 個にして、それぞれ違う明るさにする（抵抗の値を [計算ツール](../tools/index.md#led) で決める）。
2. 抵抗とコンデンサを 0805 にして、基板を 30 × 20 mm 以下にする。
