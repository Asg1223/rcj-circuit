# 2-5 デザインルールと DRC

## ねらい

- 発注先の製造能力に合わせて、デザインルールを設定できる
- DRC（デザインルールチェック）のエラーを読んで直せる

## デザインルールとは

基板メーカーには「これより細い配線・狭い間隔は作れない」という限界があります。KiCad に限界を教えておくと、DRC で違反を見つけてくれます。

例：JLCPCB（2 層基板）の公開している値と、教材の設定

| 項目 | JLCPCB の限界（2 層） | 教材の設定（余裕をもたせた値） |
|---|---|---|
| 配線の最小幅 | 0.127 mm（5 mil） | 0.2 mm |
| 配線の最小間隔 | 0.127 mm | 0.2 mm |
| ビアの穴の最小 | 0.3 mm | 0.3 mm |
| ビアの直径 | — | 0.6 mm |
| 銅と基板の端 | — | 0.3 mm |

!!! warning "値は変わることがある"
    メーカーの製造能力は変わることがあります。発注する前に、メーカーの「Capabilities（製造能力）」のページで最新の値を確かめてください。

## 手を動かす：ルールを入れる

1. 基板エディタで「ファイル → 基板設定」を開きます。
2. 「デザインルール → 制約」に、上の表の値を入れます。
3. 「ネットクラス」で、Default と Power の幅・間隔を決めます（[2-4](2-4-layout.md)）。

## DRC を走らせる

「検査 → デザインルールチェッカー」で「DRC を実行」を押します。

| よく出るエラー | 意味 | 直し方 |
|---|---|---|
| Clearance violation | 違うネットの銅が近すぎる | 配線をずらす、細くする |
| Unconnected items | ラッツネストが残っている（つなぎ忘れ） | 配線する |
| Courtyards overlap | 部品の占める範囲が重なっている | 部品を離す |
| Track has unconnected end | 配線の先がどこにもつながっていない | 余った配線を消す |
| Hole clearance | 穴と銅が近すぎる | 離す |
| Board has malformed outline | 外形が閉じていない | Edge.Cuts の線の端をつなぐ |
| Schematic parity（回路図との不一致） | 回路図と基板が合っていない | ++f8++ で更新する |

!!! note "GitHub Actions の DRC"
    push すると KiCad 10 で `kicad-cli pcb drc --schematic-parity` が走ります。回路図と基板の不一致も調べるので、回路図を直して基板を更新し忘れると、Actions が赤になります。

## チェック問題

1. 「Unconnected items」が残ったまま発注するとどうなりますか。
2. JLCPCB の限界が 0.127 mm なのに、教材では 0.2 mm にしているのはなぜですか。

??? success "答え"
    1. つながっていない配線があるので、その部分が動かない。必ず 0 にする。
    2. 限界ぎりぎりは不良が出やすく、手はんだでもショートしやすいから。余裕をもたせる。
