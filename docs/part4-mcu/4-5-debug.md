# 4-5 デバッグ用の端子と審判モジュール

## ねらい

- デバッグに役立つ LED・スイッチ・測定点を基板に入れられる
- 審判モジュールの入力を安全な回路でつなげられる

## デバッグに役立つもの

| もの | 役に立つ場面 |
|---|---|
| 電源 LED | 電気が来ているか一目でわかる（電源基板の D2） |
| 状態表示の LED | プログラムがどこまで動いたか、エラーの種類 |
| ブザー | 電池が少ない、などを音で知らせる |
| スタートボタン | 練習のときにロボットを動かす |
| テストポイント | オシロスコープやテスターを当てる |
| 予備のピン | あとで機能を足すときに使う |

開発ボード（Arduino Nano）には LED（D13）が付いているので、教材のメイン基板には別の LED を付けていません。ピンが足りないときは、こうしたボードの部品を活用します。

## 審判モジュール

国際大会（世界大会など）では、審判が試合の開始・停止を、通信モジュールからロボットに送ります。ロボットとは **2.54 mm の GPIO ピン 1 本**でつなぎます（[0-2](../part0-intro/0-2-rules.md)）。くわしい信号の決まりは、その年のルールと大会の案内を必ず確かめてください。

教材のメイン基板では、次のようにしています。

```
J9（ピンヘッダ 1×2）
  1 REF_PIN ── R9 1 kΩ ──┬── REF_IN（Nano の D8）
                         │
                        R10 100 kΩ
                         │
  2 GND ─────────────────┴── GND
```

- **R9（1 kΩ）**：まちがって高い電圧をかけたときや、静電気から、マイコンのピンを守る
- **R10（100 kΩ）**：モジュールをつないでいないときに、入力が浮かないように 0 に決める

!!! tip "3.3 V の信号を 5 V のマイコンで読む"
    審判モジュールの信号が 3.3 V でも、ATmega328P は 3.0 V 以上を 1 と読むので読めます。ただし余裕が小さいので、心配なら [4-2](4-2-level.md) の方法で変換します。

## チェック問題

1. 審判モジュールの入力にプルダウン抵抗を付けないと、何が起こりますか。
2. デバッグ用の LED をロボットの外から見える赤い LED にしてはいけない理由は何ですか。

??? success "答え"
    1. モジュールを外したときに入力が浮いて、0 と 1 がでたらめに読め、勝手にスタートしたり止まったりする。
    2. 相手のロボットがボールとまちがえるおそれがあり、ルールで隠すように決められているから。
