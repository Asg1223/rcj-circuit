# H6 モータドライバ基板

**時間の目安：3 時間**　｜　対応：[第6部](../part6-motors/index.md)

## ステップ

- [ ] モータのデータシートで、ロック電流と定格電圧を調べる（[6-1](../part6-motors/6-1-dc-motor.md)）
- [ ] ドライバ IC を選ぶ（電圧・電流・電流制限・パッケージ）（[6-2](../part6-motors/6-2-h-bridge.md)）
- [ ] 電流制限の抵抗を計算する（[計算ツール](../tools/index.md#ilim)）
- [ ] データシートの推奨回路どおりに回路図を描く（VM のコンデンサ）
- [ ] 入力のつなぎ方（IN1 = 向き、IN2 = PWM など）を決め、メイン基板のピン表と合わせる
- [ ] 配置：電力（VBAT・出力）と信号を分ける
- [ ] 放熱パッドの下にサーマルビア、裏を GND ベタ
- [ ] 出力の配線を、電流に合わせて太く（[計算ツール](../tools/index.md#trace)）
- [ ] DRC を 0 に

## 合格条件

| 項目 | 目安 |
|---|---|
| ERC・DRC のエラー | 0 |
| 電流制限 | ロック電流より小さく、走行の電流より大きい |
| VM のパスコンと IC の距離 | 3 mm 以内 |
| 出力の配線の幅 | 電流制限の値で温度上昇 10 ℃ 以下の幅 |

## 困ったとき

- **信号の配線が電力の配線と交差する**：ドライバ IC を回転させて、入力と出力の側を分ける（[6-5](../part6-motors/6-5-motor-board.md)）。

## 発展課題

1. **キッカー基板**（[第7部](../part7-kicker/index.md)）を設計する。ネットクラス HV（間隔 0.6 mm）を作り、高電圧の配線を分ける。安全の部品（放電抵抗・表示 LED・ゲートのプルダウン・測定点）を忘れない。
2. ドリブラー用の出力（ESC の信号）を足す（[6-6](../part6-motors/6-6-dribbler.md)）。
