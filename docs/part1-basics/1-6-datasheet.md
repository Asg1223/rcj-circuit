# 1-6 データシートの読み方

## ねらい

- データシートの「絶対最大定格」と「推奨動作条件」のちがいを説明できる
- データシートから、ピン配置・推奨回路・パッケージの寸法を見つけられる

## データシートの構成

部品メーカーが出している説明書を**データシート**と言います。英語のものが多いですが、見る場所は決まっています。

| 章（英語） | 何が書いてあるか | 見るとき |
|---|---|---|
| Features | 特徴のまとめ | 候補を選ぶとき |
| Pin Configuration | ピンの番号と名前 | 回路図・フットプリントを作るとき |
| **Absolute Maximum Ratings** | 絶対最大定格：**一瞬でもこえたら壊れる**値 | 電圧の余裕を確かめるとき |
| **Recommended Operating Conditions** | 推奨動作条件：**この中で使う**範囲 | 電源電圧を決めるとき |
| Electrical Characteristics | 電気的特性（標準値・最小・最大） | 計算するとき |
| Typical Application | 典型的な使い方の回路 | **回路図はここをまねる** |
| Layout Guidelines | 基板の描き方の注意 | 配置・配線のとき |
| Package / Mechanical | 寸法図 | フットプリントを確かめるとき |

!!! warning "「絶対最大定格の中ならOK」ではない"
    絶対最大定格は「ここをこえたら壊れる」線です。ふだんは**推奨動作条件**の中で使います。たとえば DRV8871 の VM（モータ電源）の推奨は 6.5〜45 V です。

## 例：DRV8871 を読む

モータドライバ基板で使う TI の DRV8871 で練習します。データシートは <https://www.ti.com/product/DRV8871> から読めます。

1. **ピン配置**：1 GND、2 IN2、3 IN1、4 ILIM、5 VM、6 OUT1、7 PGND、8 OUT2、裏の放熱パッド。
2. **推奨回路**：VM の近くに 0.1 µF のセラミックコンデンサと、大きめの電解コンデンサ。ILIM と GND の間に抵抗。
3. **電流制限の式**：$I_{TRIP} = 64 / R_{ILIM}$（$R_{ILIM}$ は kΩ）。32 kΩ なら約 2 A。$R_{ILIM}$ の最小は 15 kΩ。
4. **レイアウトの注意**：放熱パッドの下にビアをたくさん打って、裏の GND とつなぐ。

教材の基板がこのとおりになっているか、[6-5](../part6-motors/6-5-motor-board.md) で確かめます。

## ピン番号のわなに注意

同じ「部品」でも、パッケージ（形）によってピン番号が違うことがあります。また、KiCad のフットプリントのピン番号と、部品の極性の対応も確かめる必要があります。

!!! example "教材で実際にあった例：XT30"
    KiCad の XT30 のフットプリント（AMASS_XT30PW）は、**1 番ピンが「−」、2 番ピンが「＋」** です。回路図で 1 番を電池の＋にすると、基板が逆になります。シルクの「+」「−」の文字と、ピン番号を必ず見くらべてください。

## 手を動かす

1. AP2112K-3.3（電源基板の 3.3 V レギュレータ）のデータシートを探し、次の値を書き出してください。
    - 入力電圧の最大（推奨）
    - 出力電流の最大
    - 入力・出力に必要なコンデンサの容量
2. 74HC165 のデータシートで、PL（パラレルロード）が L のときに何が起こるか読んでください。

??? success "答えの例"
    1. 入力は 6 V まで（5 V から 3.3 V を作るのに使う）、出力 600 mA、入力・出力ともに 1 µF のセラミックコンデンサ。
    2. 8 本の入力（D0〜D7）の状態が取りこまれる。CP（クロック）は無視される。

## チェック問題

1. 「Absolute Maximum Ratings」の値ぎりぎりで使ってよいですか。
2. 回路図を描くとき、まず見るべきデータシートの章はどこですか。

??? success "答え"
    1. よくありません。推奨動作条件の中で、さらに余裕をもって使います。
    2. Typical Application（典型的な回路）。そこに必要なコンデンサや抵抗が書いてあります。
