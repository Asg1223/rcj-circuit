# 1-7 シミュレーション（ngspice）

## ねらい

- KiCad の回路図エディタで、簡単な回路のシミュレーションを動かせる
- RC フィルタの電圧の変化をグラフで見られる

## 理論

KiCad には **ngspice** という回路シミュレータが入っています。部品を基板に付ける前に、電圧や電流がどう変わるかを計算できます。

| 解析 | 何がわかるか | 例 |
|---|---|---|
| 動作点（.op） | 電圧・電流の値 | 分圧の出力電圧 |
| 過渡（.tran） | 時間とともにどう変わるか | コンデンサの充電、PWM |
| 交流（.ac） | 周波数ごとの通りやすさ | RC フィルタ |

## 手を動かす：RC の充電を見る

1. KiCad で新しいプロジェクト `sim-rc` を作り、回路図エディタを開きます。
2. 次の部品を置きます（++a++ で追加）。
    - `Simulation_SPICE:VPULSE`（パルス電源）
    - `Device:R`（1 kΩ）
    - `Device:C`（1 µF）
    - `power:GND`（ngspice では GND の名前が `0` として扱われます）
3. VPULSE → R → C → GND とつなぎ、R と C の間に `OUT` というラベルをつけます。
4. VPULSE の値をダブルクリックで開き、次のように設定します。
    - 初期値 0 V、パルス 5 V、立ち上がり 1 µs、幅 5 ms、周期 10 ms
5. メニューの「検査 → シミュレーター」を開き、「解析の設定」で **過渡解析** を選び、時間 20 ms、ステップ 10 µs にします。
6. 「実行」を押し、信号 `V(/OUT)` を追加してグラフを見ます。

時定数 $\tau = RC = 1\,\text{ms}$ なので、約 1 ms で 63 %、約 5 ms でほぼ 5 V になります。

!!! tip "部品のモデル"
    抵抗・コンデンサ・電源はそのままシミュレーションできます。トランジスタや IC は、メーカーが出している SPICE モデルを読みこむ必要があります。最初は R・C・L・ダイオードだけで試すのがおすすめです。

## やってみよう

1. R を 100 Ω にすると、グラフはどう変わりますか。
2. 「交流解析」で、1 Hz〜1 MHz の範囲の `V(/OUT)` を見て、カットオフ周波数（−3 dB）が $\frac{1}{2\pi RC}$ と合うか確かめてください。

## つまずきポイント

- **「GND がない」エラー**：必ず `power:GND` を置いてください。
- **値の単位**：KiCad の値欄では `1k`、`1u`（µ は u）、`10m`（ミリ）と書きます。`1M` は「メガ」ではなく「ミリ」と読まれることがあるので、メガは `1Meg` と書きます。

??? example "もっと深く：キッカーをシミュレーションする"
    ソレノイドは「インダクタ（L）と抵抗（R）の直列」として近似できます。コンデンサ（1000 µF、40 V）→ スイッチ → L（数 mH）＋ R（数 Ω）の回路で過渡解析をすると、流れる電流の最大値とその時間がわかります。フライバックダイオードがないと、スイッチを切った瞬間に大きな電圧が出ることも確かめられます（[7-3](../part7-kicker/7-3-discharge.md)）。
