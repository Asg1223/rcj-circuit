# 5-1 IR 受光モジュールの回路

## ねらい

- IR 受光モジュールの 3 本のピンと、推奨回路を説明できる
- モータのノイズから受光モジュールを守る回路を描ける

## 理論

### ボールの赤外線と受光モジュール

RCJ の IR ボールは、40 kHz で点滅する赤外線を、さらに決まったパターン（明るさを段階的に変える）で出しています。くわしい仕様はルールの付録と [機械学習の教材 1-1](https://asg1223.github.io/rcj-soccer-ml/) にあります。

ボールを見るには、**特定の周波数の赤外線だけに反応する受光モジュール**（Vishay の TSSP・TSOP 系など）がよく使われます。中に、受光部・増幅・フィルタ・検波が入っていて、

- 赤外線を受けている間は出力が **L（0）**
- 受けていないときは **H（1）**

になります（出力は「L がアクティブ」）。ボールが近い・明るいほど、L の時間が長くなります。

### 3 本のピン

| ピン | 名前 | つなぐ先 |
|---|---|---|
| 1 | OUT | マイコン、または 74HC165 の入力 |
| 2 | GND | GND |
| 3 | Vs | 電源（フィルタを通して） |

!!! warning "ピン配置は製品ごとに違う"
    上の並びは KiCad の `TSOP382xx` シンボル・`Vishay_MINICAST-3Pin` フットプリントの例です。メーカーや形（パッケージ）が変わると、ピンの順番が違うことがあります。必ず使う部品のデータシートで確かめてください。

### 推奨回路：電源のフィルタ

受光モジュールは小さな信号を大きく増幅しているので、**電源のノイズにとても弱い**です。データシートには、電源に抵抗とコンデンサを入れる回路が推奨されています。

```
+5V ── R（100 Ω 前後）──┬── Vs（受光モジュール）
                        │
                        C（0.1 µF 以上）
                        │
GND ────────────────────┴── GND
```

- R と C で RC フィルタ（[1-3](../part1-basics/1-3-capacitor.md)）になり、モータなどのノイズを弱めます。
- **1 個ごとに R と C を付け、C はモジュールのすぐ近くに**置きます。
- 値は製品のデータシートの推奨値に合わせてください（教材の基板は 100 Ω と 0.1 µF）。

### 出力のプルアップ

多くの受光モジュールは、出力の中にプルアップ抵抗が入っています。外にプルアップを付ける必要があるかは、データシートの「Output」の説明で確かめます。

## 手を動かす

=== "KiCad"

    `kicad/ir-ring/ir-ring.kicad_sch` を開き、U1（受光 0）と R1・C1 のつながりを確かめてください。VS0 に PWR_FLAG が付いているのはなぜですか（[2-2](../part2-kicad/2-2-schematic.md)）。

=== "実機"

    ブレッドボードに受光モジュール 1 個と 100 Ω・0.1 µF を付け、OUT に LED（＋抵抗、カソードを OUT 側）をつなぎます。IR ボールを近づけると LED が光ります（L で光る）。テレビのリモコン（38 kHz 前後）でも反応することがあります。

## チェック問題

1. 受光モジュールの出力は、ボールを見ているとき H と L のどちらですか。
2. 電源のフィルタのコンデンサを、受光モジュールから遠くに置くと何が困りますか。

??? success "答え"
    1. L（多くの製品）。データシートで確かめる。
    2. 配線が長いぶんノイズを拾い、フィルタの効果が小さくなる。
