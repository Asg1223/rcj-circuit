# 3-6 電池電圧の監視と測定点

## ねらい

- 電池電圧をマイコンで測り、低くなったら止める仕組みを作れる
- 検査で電圧を測るための測定点（テストポイント）を基板に入れられる

## 電池電圧をマイコンで測る

[1-2](../part1-basics/1-2-divider.md) の分圧を使います。教材の電源基板では、R2（100 kΩ）と R3（33 kΩ）で分圧し、C7（0.1 µF）でノイズをとって、メイン基板の A7 に送っています。

### 低電圧で止める

リポは 1 セル 3.0 V より下げると傷みます。マイコンのプログラムで次のようにします。

```cpp
const float CUTOFF = 3.3 * 3;      // 3S の下限（余裕をみて 9.9 V）
float vbat = readBattery();        // 1-2 の計算
if (vbat < CUTOFF) {
  stopMotors();                    // モータを止める
  blinkWarning();                  // LED やブザーで知らせる
}
```

!!! tip "一瞬の電圧低下で止めない"
    モータの起動で一瞬だけ電圧が下がるので、**何回か続けて下限を下回ったら止める**、または平均をとるようにします。

## 測定点（テストポイント）

ルールでは、検査で電圧を測りやすくすること、測る場所はカバーするか安全に作ることが決められています（[0-2](../part0-intro/0-2-rules.md)）。

教材の電源基板には次のテストポイントがあります。

| 記号 | ネット | 使いみち |
|---|---|---|
| TP1 | VBAT | 電池の電圧を測る |
| TP2 | GND | テスターの黒をはさむ |
| TP3 | +5V | 5 V が出ているか確かめる |

キッカー基板にも、高電圧（HV）を測る TP1 があります。高電圧の測定点は、ふだんは**絶縁のキャップやカバー**で覆い、検査のときだけ外します（[7-4](../part7-kicker/7-4-safety.md)）。

!!! tip "テストポイントの形"
    ワイヤを曲げたループ型（`TestPoint_Loop`）は、テスターのクリップではさみやすいです。基板の端の近く、ロボットを組み立てても手が届く場所に置きます。

## 手を動かす

1. `kicad/power/power.kicad_pcb` で TP1〜TP3 の位置を確かめてください。ロボットに組んだとき、上からテスターを当てられそうですか。
2. 自分のロボットで、電池電圧を表示するプログラムを書き、テスターで測った値と比べてください。ずれが 0.1 V より大きいなら、分圧の抵抗の実際の値を測って計算に入れます。

## チェック問題

1. 電池電圧の測定に 0.1 µF のコンデンサを付けるのはなぜですか。
2. 高電圧の測定点をカバーしないとどんな危険がありますか。

??? success "答え"
    1. 分圧の抵抗が大きいので、ADC が読むときの電圧の落ちこみやノイズを防ぐため。
    2. 指や工具が触れて感電・ショートするおそれがある。
