# 0-3 道具をそろえる

## ねらい

- 回路づくりに必要な道具と、その使いみちを言える
- KiCad 10 をインストールして起動できる

## そろえる道具

| 道具 | 使いみち | 選び方のポイント |
|---|---|---|
| デジタルテスター | 電圧・抵抗・導通（つながっているか）を測る | 導通のブザーがあるもの。オートレンジだと楽 |
| はんだごて | 部品を基板に付ける | 温度調節つき（300〜350 ℃ が使える）。こて先は細めと太めの 2 本 |
| はんだ・フラックス | はんだ付け | 直径 0.6〜0.8 mm の糸はんだ。フラックスはペン型が便利 |
| はんだ吸い取り線 | まちがえた部品を外す、ブリッジを取る | 幅 1.5〜2 mm |
| ピンセット | 小さい部品（0805 など）をつまむ | 先が細くて曲がっていないもの |
| ルーペ | はんだの状態を見る | 10 倍くらい。スマホのカメラでもよい |
| 安定化電源（電流制限つき） | 初めて電気を入れるときに使う | **電流の上限を決められる**もの。0〜30 V・3 A 程度 |
| 圧着工具 | XH・PH コネクタのケーブルを作る | コネクタの種類に合うもの（[8-3](../part8-system/8-3-harness.md)） |
| 作業マット | 机を守る・部品がなくならない | 耐熱のシリコンマット |
| リポ用の安全袋 | 電池の保管・充電 | ルールで必要（[0-4](0-4-safety.md)） |

!!! tip "あると便利なもの"
    - **オシロスコープ**：PWM やシリアル通信の波形が見えます。安いハンディ型でも役に立ちます（[9-4](../part9-build/9-4-debug.md)）。
    - **USB 電流チェッカー**：マイコンが何 mA 使っているかがすぐわかります。

## KiCad 10 をインストールする

KiCad は無料・オープンソースの回路設計ソフトです。回路図・基板レイアウト・製造データの出力まで、1 つでできます。

=== "Windows"

    1. <https://www.kicad.org/download/windows/> を開きます。
    2. 一番上の **KiCad 10.x** のインストーラーをダウンロードします。
    3. インストーラーを実行し、標準の設定のまま進めます（ライブラリも一緒に入ります）。
    4. スタートメニューから **KiCad** を起動します。

=== "Mac"

    1. <https://www.kicad.org/download/macos/> を開きます。
    2. **KiCad 10.x** の `.dmg` をダウンロードします。
    3. `.dmg` を開き、`KiCad` フォルダを「アプリケーション」へドラッグします。
    4. 初めて起動するときに「開いてよいか」と聞かれたら「開く」を選びます。

=== "Linux（Ubuntu）"

    ```bash
    sudo add-apt-repository ppa:kicad/kicad-10.0-releases
    sudo apt update
    sudo apt install kicad
    ```

起動したら、メニューの「ヘルプ → KiCad について」でバージョンが **10.** で始まることを確かめてください。

!!! note "この教材の KiCad データ"
    教材の KiCad データは KiCad 7 の形式で保存してあります。KiCad 10 で開くと「新しい形式に変換します」と出ることがあります。そのまま進めて大丈夫です。保存すると KiCad 10 の形式になり、古い KiCad では開けなくなります。

## 教材のデータを手元に置く

=== "Git を使う（おすすめ）"

    ```bash
    git clone https://github.com/Asg1223/rcj-circuit.git
    cd rcj-circuit
    ```

=== "zip でダウンロード"

    1. <https://github.com/Asg1223/rcj-circuit> を開きます。
    2. 緑の「Code」ボタン → 「Download ZIP」を押します。
    3. 展開したフォルダの中の `kicad/` を見ます。

`kicad/h1-led/h1-led.kicad_pro` をダブルクリックすると、KiCad で H1 の LED 基板が開きます。

## チェック問題

1. 初めて基板に電気を入れるとき、安定化電源で何を決めておきますか。
2. テスターの「導通」モードは何を調べるときに使いますか。

??? success "答え"
    1. 電流の上限（電流制限）。まちがいがあっても大きな電流が流れず、部品が燃えにくくなります。
    2. 2 点が電気的につながっているか（ショートしていないか、配線が切れていないか）。
