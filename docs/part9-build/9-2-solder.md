# 9-2 はんだ付け

## ねらい

- チップ部品（0805・1206）と SOT-23・SOIC を手はんだで付けられる
- 放熱パッドのある部品を付ける方法を言える

## 順番

**背の低いものから**付けます。

1. チップ抵抗・コンデンサ、小さい IC（SOT-23、SOIC）
2. 放熱パッドのある IC（HSOP-8 など）
3. ダイオード・MOSFET（SMA、DPAK）
4. 足のある部品：ピンソケット、コネクタ、テストポイント
5. 電解コンデンサ（背が高い）

## チップ部品の付け方

1. 片方のパッドにだけ、少しはんだを乗せる（予備はんだ）
2. ピンセットで部品を置き、こてで予備はんだを溶かして片側を固定
3. 位置がずれていないか見て、ずれていたら直す
4. もう片方をはんだ付けする
5. 最初の側も、はんだを少し足して付けなおす

## IC（SOIC・SOT-23）の付け方

1. 1 番ピンの向きを確かめる（シルクの●と、部品の印）
2. 角のピン 1 本だけ付けて固定
3. 対角のピンを付けて、全部のピンがパッドに乗っているか確かめる
4. 残りのピンを付ける。ブリッジ（隣のピンとつながる）したら、フラックスを塗ってこてでなぞるか、吸い取り線で取る

## 放熱パッドのある部品（DRV8871 など）

裏の放熱パッドは、こてが届きません。

| 方法 | やり方 |
|---|---|
| 裏から流しこむ | 基板のサーマルビアに、裏からはんだを流しこむ（教材のフットプリントにはビアがある）。熱が逃げるので、太いこて先・高めの温度で |
| ホットエアー | パッドにはんだを薄く乗せ、部品を置いて、熱風で全体を溶かす |
| ホットプレート・リフロー | クリームはんだを塗って、基板ごと温める。ステンシル（メタルマスク）があるときれいに塗れる |

!!! tip "PCBA を使う"
    放熱パッドの部品がうまく付けられないときは、その部品だけでも JLCPCB の実装サービス（[9-1](9-1-order.md)）を使うと確実です。

## 付けたあとのチェック

- [ ] ルーペで全部のはんだを見る（つやがある、山形、ブリッジがない）
- [ ] 部品の向き（ダイオード・LED・電解コンデンサ・IC）
- [ ] フラックスの残りを、アルコールでふき取る

## チェック問題

1. 背の高い部品から付けると、何が困りますか。
2. IC のピンのブリッジを直す方法を 2 つ挙げてください。

??? success "答え"
    1. 背の高い部品がじゃまで、低い部品にこてが届きにくくなる。基板を裏返したときに安定しない。
    2. フラックスを塗ってこてでなぞる、はんだ吸い取り線で取る。
