# 9-1 発注（JLCPCB）

## ねらい

- ガーバーを JLCPCB に注文できる
- 注文の選択肢（板厚・色・表面処理・実装）を選べる

## 注文の前に

- [ ] ERC のエラーが 0
- [ ] DRC のエラー・未接続が 0
- [ ] 3D ビューアでコネクタの向き・部品の当たりを確かめた
- [ ] コネクタのピン表を、相手の基板と見くらべた
- [ ] 取りつけ穴の位置を、機構（CAD）と合わせた
- [ ] 基板の名前・バージョン（v1 など）・日付をシルクに入れた
- [ ] ガーバー（とドリル）を出して、ガーバービューアで見た

!!! tip "ガーバービューアで最後に見る"
    KiCad の「ガーバービューアー」で、出力したガーバーを開いて見ます。外形がない、シルクがない、穴がない、といったまちがいに気づけます。JLCPCB も、アップロードすると画面で表示してくれます。

## 注文の手順（JLCPCB）

画面のデザインは変わることがありますが、流れは同じです。

1. <https://jlcpcb.com/> でアカウントを作る
2. 「Order now」などから、ガーバーの zip をアップロードする（GitHub Actions の `kicad-outputs` の中の `gerbers/` を zip にしたもの、または [2-6](../part2-kicad/2-6-output.md) で手で出したもの）
3. 大きさと層の数が自動で読まれるので、確かめる
4. 主な選択肢を選ぶ（下の表）
5. 枚数を選ぶ（最小 5 枚が多い）
6. 送料・配送方法を選んで注文する

| 項目 | よく選ぶ値 | 説明 |
|---|---|---|
| Layers（層） | 2 | 教材の基板はすべて 2 層 |
| Thickness（板厚） | 1.6 mm | 標準。軽くしたいなら 1.2 mm も |
| Color（色） | 緑 | 緑以外は日数・値段が変わることがある |
| Surface finish（表面処理） | HASL（lead free） | ふつうはこれ。細かい部品が多いなら ENIG |
| Copper weight（銅の厚さ） | 1 oz | 大電流なら 2 oz も検討（[2-4](../part2-kicad/2-4-layout.md)） |
| 注文番号の印字 | 場所を指定・印字なし（有料のことがある） | 何もしないと、シルクのどこかに番号が入ることがある |

!!! warning "値段・選択肢は変わる"
    値段、最小枚数、選択肢、送料は変わることがあります。注文の前に画面でよく確かめ、わからないところは先生や大人と一緒に確認してください。

### 部品の実装（PCBA）

JLCPCB には、部品のはんだ付けまでしてくれるサービス（PCBA）もあります。手はんだがむずかしい部品（放熱パッドのある IC など）がある基板で便利です。

- 部品表（BOM）と部品の座標（CPL・ポジションファイル）を、指定の形式で出します。
- 部品は JLCPCB（LCSC）にあるものから選び、部品番号をシンボルのプロパティに書いておきます。
- 足のある部品（コネクタなど）は、自分ではんだ付けすることも多いです。

## メーカーを比べる

| メーカー | 特徴 |
|---|---|
| JLCPCB（中国） | 安い、速い、実装サービスが充実。教材の前提 |
| PCBWay（中国） | 選択肢が多い、特殊な基板にも対応 |
| Elecrow（中国） | 実装・3D プリントなども |
| 国内のメーカー（P板.com など） | 日本語で相談できる、届くのが速い。値段は高め |

比べるときは、**値段だけでなく、届くまでの日数（大会に間に合うか）・最小の配線幅・送料**も見ます。

## チェック問題

1. 注文の前に、ガーバーをガーバービューアで見る理由は何ですか。
2. 放熱パッドのある IC が多い基板で、PCBA を使うよい点は何ですか。

??? success "答え"
    1. 外形・シルク・穴の出し忘れなど、出力のまちがいを見つけるため。
    2. 手はんだがむずかしい部品を、きれいに確実に付けてもらえる。
