# 9-5 車検の準備と BOM

## ねらい

- 大会の検査で確かめられる電気のことを、事前に自分たちで確かめられる
- 部品表（BOM）を作って提出できる

## 自分たちで事前にする車検（電気）

- [ ] 大きさ・重さがルールの範囲内（電池・カバー込み）
- [ ] 電源スイッチ（非常停止）にすぐ手が届く
- [ ] キッカーの電圧が 48 V 以下。測定点にテスターを当てられ、ふだんはカバーされている
- [ ] インフラレッド：IR を出す部品がない（ToF・IR LED など）
- [ ] 外から見える赤い光がない
- [ ] リポは安全袋に入れて持ってきた。電池は固定されている
- [ ] 配線がむき出し・ぶら下がりになっていない
- [ ] キッカーの強さが試験に合う（弱いモードがある）
- [ ] 審判モジュールの端子（大会で必要なら）

## BOM（部品表）

国際大会では、ロボットに使った部品の一覧（BOM）の提出を求められることがあります。形式は大会の案内に従います。

KiCad から部品表を出す（[2-6](../part2-kicad/2-6-output.md)）と、基板の部品の一覧は自動で作れます。モータ、電池、マイコンボード、カメラなど、基板以外の部品は自分で足します。

| 列の例 | 内容 |
|---|---|
| 部品名・型番 | DRV8871DDA、Arduino Nano など |
| 数 | |
| 購入先 | |
| 値段 | |
| 自作か市販か | 基板は「自作（チームで設計）」 |

!!! tip "設計資料も見せられるように"
    インタビューや審査で「どこを自分たちで設計したか」を聞かれることがあります。回路図の PDF（GitHub Actions の Artifacts にある）と、基板の写真をすぐ見せられるようにしておくと説明しやすいです。

## チェック問題

1. キッカーの測定点は、ふだんはどうしておきますか。
2. BOM に、基板以外で入れ忘れやすい部品を 3 つ挙げてください。

??? success "答え"
    1. カバー（絶縁キャップなど）で覆っておき、検査のときに外して測れるようにする。
    2. 電池、モータ、マイコンボード、カメラ、ケーブル・コネクタ、ネジなど（このうち 3 つ）。
