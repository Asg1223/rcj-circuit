# 付録：用語集

| 用語 | 意味 |
|---|---|
| ADC | アナログの電圧を数字に変える回路。マイコンの analogRead |
| BOM | 部品表（Bill of Materials） |
| DRC | デザインルールチェック。基板が作れるか、つなぎ忘れがないか調べる |
| ERC | 電気的ルールチェック。回路図のつなぎ忘れ・電源の入れ忘れを調べる |
| ESC | ブラシレスモータを動かすコントローラ |
| GND | 電圧の基準（0 V） |
| H ブリッジ | スイッチ 4 個でモータの向きを変える回路 |
| I2C | 2 本の線（SDA・SCL）で何台もの機器と話す通信 |
| IMU | ジャイロ・加速度などを測るセンサ |
| LDO | 入力と出力の差を熱にして電圧を下げるレギュレータ |
| MOSFET | ゲートの電圧で ON/OFF するトランジスタ |
| PWM | ON/OFF の時間の割合で平均の電圧を変える方法 |
| PWR_FLAG | KiCad の ERC に「ここに電源が来ている」と教える記号 |
| SPI | クロックに合わせて速く送る通信 |
| UART | TX・RX の 2 本で送る通信（シリアル） |
| ガーバー | 基板メーカーに送る、各層の絵のデータ |
| コートヤード | 部品が占める範囲。重なると DRC が知らせる |
| サーマルビア | 熱を裏に逃がすためのたくさんのビア |
| シルク | 基板に印刷する文字や線 |
| デューティ比 | PWM の ON の時間の割合 |
| ネット | 電気的につながっているピンのまとまり |
| ネットクラス | ネットの種類ごとに、配線の太さ・間隔を決める設定 |
| パスコン | IC の電源ピンの近くに置く小さなコンデンサ |
| ビア | 表と裏の配線をつなぐ穴 |
| フットプリント | 基板の上での部品の形（パッド） |
| フライバックダイオード | コイルの電流を切ったときに出る高い電圧を逃がすダイオード |
| プルアップ・プルダウン | 入力の電圧が浮かないように、抵抗で電源・GND に引くこと |
| ベタ | 空いたところを銅で塗りつぶしたもの（ゾーン） |
| ラッツネスト | まだ配線していないつながりを示す細い線 |
