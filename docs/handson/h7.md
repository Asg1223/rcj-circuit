# H7 実装して、はじめての通電

**時間の目安：3 時間**　｜　対応：[9-2](../part9-build/9-2-solder.md)、[9-3](../part9-build/9-3-first-power.md)

!!! danger "安全"
    [0-4 安全](../part0-intro/0-4-safety.md) を読んでから始めます。電池ではなく、**電流制限つきの安定化電源**を使います。

## ステップ

- [ ] 届いた基板を見て、ショート・欠け・穴の位置を確かめる
- [ ] 部品をそろえ、部品表と数を合わせる
- [ ] 背の低い部品から、はんだ付けする
- [ ] ルーペでチェック（ブリッジ・向き）
- [ ] 電源と GND の間の抵抗をテスターで測る（0 Ω に近くない）
- [ ] 安定化電源を 11.1 V・電流の上限 100 mA にして、電源基板につなぐ
- [ ] 電流と、各部の電圧を測る（[9-3](../part9-build/9-3-first-power.md) の表）
- [ ] 逆につないでも出力が出ない（逆接続保護）ことを確かめる
- [ ] メイン基板をつなぎ、マイコンに書きこむ

## 合格条件（電源基板）

| 測る場所 | 目安（入力 11.1 V） |
|---|---|
| 無負荷の電流 | 30 mA 以下（LED と レギュレータの分） |
| +5V | 4.9〜5.1 V |
| +3V3 | 3.25〜3.35 V |
| VBAT_SENSE | 2.7〜2.8 V |
| 逆につないだときの VBAT | 0 V |

## 困ったとき

- **電流が上限に張りつく**：すぐ切る。ショート・部品の向き（電解コンデンサ・ダイオード・IC）を確かめる。
- **5 V が出ない**：U1 の向き、入力の電圧（8 V 以上か）、はんだ。

## 発展課題

1. 5 V に 0.5 A の負荷（抵抗やモータ）をつないで、U1 の温度を測る。
2. VBAT を 9.9 V（3S の下限）まで下げても 5 V が出るか確かめる。
