# 8-3 ハーネス（ケーブル）の作り方

## ねらい

- XH コネクタのケーブルを圧着で作れる
- 試合でケーブルが抜けない・切れない工夫ができる

## 道具と材料

| もの | 例 |
|---|---|
| 圧着工具 | コネクタの端子（コンタクト）の大きさに合うもの |
| 電線 | 信号は AWG 26〜24、電源は AWG 22〜18（太いほど数字が小さい） |
| ハウジング・コンタクト | XH なら XHP-○（ハウジング）と SXH-001T-P0.6（コンタクト）など |
| 熱収縮チューブ | はんだ付けした部分の絶縁 |

## 圧着の手順（XH）

1. 電線の先を 2 mm くらいむく
2. 圧着工具の正しい穴に、コンタクトを向きに気をつけて入れる
3. 心線の部分と、被覆の部分を、それぞれ圧着する（2 か所）
4. 軽く引っぱって抜けないことを確かめる
5. ハウジングに「カチッ」と音がするまで差しこむ。**向き（ピン番号）**に注意
6. テスターの導通で、両端のピン番号が合っているか確かめる

!!! warning "はんだで済ませない"
    圧着端子をはんだ付けすると、はんだの境目で線が折れやすくなります。圧着をきちんとするのが一番丈夫です。

## 色分け

| 色 | 決まり（例） |
|---|---|
| 赤 | 電源のプラス（VBAT・5 V） |
| 黒 | GND |
| そのほか | 信号。チームで決めて表にする |

## 固定

- ケーブルは長すぎず短すぎず。基板を外せるくらいの余裕
- 結束バンドやケーブルクリップで、機体に固定
- コネクタの根元に力がかからないようにする
- 動く部分（キッカー、ドリブラー）の近くは、こすれないように通す

## チェック問題

1. 圧着したら、まず何を確かめますか。
2. ケーブルをピンと張って配線すると、何が困りますか。

??? success "答え"
    1. 引っぱって抜けないか、両端のピン番号が合っているか（導通）。
    2. 衝突や振動でコネクタが抜けたり、線が切れたりしやすい。基板の交換もしにくい。
