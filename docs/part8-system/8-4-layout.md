# 8-4 機体の中での配置

## ねらい

- 基板を機体のどこに置くか、重さ・熱・ノイズ・ルールから決められる

## 決めること

| 項目 | 考えること |
|---|---|
| 大きさ | インフラレッドは直径 22.0 cm、高さ 22.0 cm 以内（[0-2](../part0-intro/0-2-rules.md)） |
| 重さ | 1500 g 以下。電池・モータ・キッカーが重い。重心は低く、真ん中に |
| IR リング | 周りが見渡せる高さ。ほかの部品が受光モジュールの前をふさがない |
| モータドライバ | モータの近く（モータの配線が短い）。熱がこもらない |
| キッカー | ソレノイドの近く。IMU から離す。高電圧の部分にカバー |
| メイン基板 | USB が挿せる、スイッチ・LED が見える |
| 電源スイッチ | すぐ手が届く（非常停止） |
| IMU | 回転の中心の近く、水平、ソレノイド・モータから離す |
| カメラ（CoreS3） | 前が見える高さ・角度 |

## 段の例

```
最上段：IR リング基板、カメラ、電源スイッチ・取っ手
中段  ：メイン基板、電源基板、IMU
下段  ：モータドライバ基板、電池、キッカー（ソレノイド・コンデンサ）、モータ
```

## 熱

- モータドライバとレギュレータは熱くなります。ほかの部品で囲まない、風が通るようにする。
- 電池は熱に弱いので、モータドライバや抵抗の熱が当たらない場所に。

## チェック問題

1. IMU をキッカーのソレノイドの近くに置いてはいけない理由は何ですか。
2. 重い電池はどこに置くとよいですか。

??? success "答え"
    1. 蹴るときの大電流の磁気や振動で、IMU の値が乱れるから。
    2. できるだけ低い位置の真ん中（重心を低く、中心に）。
