# 9-3 はじめての通電

## ねらい

- 通電の前のチェックと、電流制限をかけた通電の手順を守れる

## 通電の前に（電源を入れずに）

- [ ] 電源と GND の間の抵抗をテスターで測る。**0 Ω に近いならショート**。電源を入れない
- [ ] 部品の向き（[9-2](9-2-solder.md) のチェック）
- [ ] コネクタの向き・ピン番号
- [ ] 高い電圧の部分（キッカー）は、まだつながない

!!! tip "抵抗が小さく見える理由"
    電源と GND の間には大きなコンデンサがあるので、テスターを当てた直後は小さい値から始まって、だんだん大きくなります。ずっと数 Ω 以下ならショートを疑います。

## 電流制限をかけて電気を入れる

1. 安定化電源の電圧を、電池と同じくらい（3S リポなら 11.1 V）に合わせる
2. 電流の上限を**小さく**する（電源基板だけなら 50〜100 mA）
3. 出力を OFF にしてから、基板につなぐ（＋と−をまちがえない）
4. 出力を ON にして、表示の電流を見る
5. 電流が上限に張りつく（電圧が下がる）なら、すぐに OFF。どこかショートしている
6. 問題なければ、各部の電圧を測る

## 電源基板で測る場所

| 測る場所 | 期待する値（入力 11.1 V） |
|---|---|
| TP1（VBAT）と TP2（GND） | 約 11.1 V |
| TP3（+5V） | 4.9〜5.1 V |
| J4 の 3 番（+3V3） | 3.25〜3.35 V |
| J4 の 2 番（VBAT_SENSE） | 11.1 × 33/133 ≒ 2.75 V |
| 電源 LED（D2） | 光る |

## 基板を 1 枚ずつ足していく

電源基板 → メイン基板 → IR リング基板 → モータ基板（モータなし）→ モータ → キッカー、の順に、1 枚つなぐたびに電流と電圧を確かめます。最後に電池につなぎます。

## チェック問題

1. 電流の上限に張りついて電圧が下がりました。何が起きていますか。
2. はじめての通電で、電池ではなく安定化電源を使う理由は何ですか。

??? success "答え"
    1. どこかでショート、または部品の向きまちがいで大きな電流が流れている。すぐに切る。
    2. 電流の上限を決められるので、まちがいがあっても大きな電流が流れず、部品が燃えにくいから。
