# ハンズオン

1 人で進める課題集です。数回に分けて、最後は実物の基板を注文・組み立てて動かします。

| 回 | 内容 | 対応する章 | 時間の目安 | 実機 |
|---|---|---|---|---|
| [H1](h1.md) | KiCad で LED 基板を作り、DRC を通す | 第2部 | 3 時間 | — |
| [H2](h2.md) | 電源基板の回路図 | 第3部 | 2 時間 | — |
| [H3](h3.md) | 電源基板のレイアウトと発注 | 第3部・第9部 | 3 時間 | 発注 |
| [H4](h4.md) | メイン基板 | 第4部 | 4 時間 | — |
| [H5](h5.md) | IR リング基板（円形） | 第5部 | 3 時間 | — |
| [H6](h6.md) | モータドライバ基板 | 第6部 | 3 時間 | — |
| [H7](h7.md) | 実装して、通電前チェック → 初通電 | 第9部 | 3 時間 | あり |
| [H8](h8.md) | 基板をつないで動作確認、車検チェックリスト | 第8部・第9部 | 3 時間 | あり |

## 各回の形

1. **時間の目安**
2. **ステップ**（チェックリスト）
3. **合格条件**（目安の数字）
4. **記録シート**（チーム用リポジトリの `records/handson.md` にコピーして使う）
5. **困ったとき**
6. **発展課題**

!!! note "自分のチームの基板で進めるとき"
    H2 以降は、教材の基板をまねるのではなく、自分のロボットに合わせて設計してかまいません。そのときは、チーム用の**非公開リポジトリ**（`rcj-circuit-team`）で作業します（[付録](../appendix/team-repo.md)）。
