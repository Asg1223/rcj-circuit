# H2 電源基板の回路図

**時間の目安：2 時間**　｜　対応：[第3部](../part3-power/index.md)

## ステップ

- [ ] 自分のロボットの消費電流の表を作る（[3-2](../part3-power/3-2-current.md)）
- [ ] 電池（セル数・容量）とコネクタを決める（[3-1](../part3-power/3-1-battery.md)）
- [ ] 入力と保護：XT30、電源スイッチの端子、ヒューズ、P-MOSFET の逆接続保護、バルクコンデンサ（[3-3](../part3-power/3-3-protection.md)）
- [ ] 5 V と 3.3 V のレギュレータを選び、データシートの推奨どおりにコンデンサを付ける（[3-4](../part3-power/3-4-regulator.md)）
- [ ] 電池電圧の分圧（[3-6](../part3-power/3-6-monitor.md)）
- [ ] 出力コネクタと、テストポイント
- [ ] **XT30 のピン番号と極性**をフットプリントエディタで確かめる
- [ ] ERC のエラーを 0 にする
- [ ] 出力コネクタのピン表を作る

## 合格条件

| 項目 | 目安 |
|---|---|
| ERC のエラー | 0 |
| 5 V の電流の余裕 | ピークの 1.5 倍以上の部品 |
| LDO の発熱 | 0.5 W 以下（[計算ツール](../tools/index.md#ldo)） |
| 電池電圧の分圧 | 満充電で ADC の上限の 95 % 以下 |
| ヒューズ | ピークより大きく、配線の許容より小さい |

## 記録シート

| 項目 | 記入 |
|---|---|
| 電池（セル数・容量・C） | |
| 平均電流・ピーク電流（VBAT・5 V・3.3 V） | |
| 選んだ部品（ヒューズ・MOSFET・レギュレータ） | |
| 分圧の抵抗と、満充電のときの ADC の電圧 | |

## 困ったとき

- **5 V のレギュレータが入力電圧に合わない**：2S なら入力 6 V 以上で使える DC-DC にする。
- **PWR_FLAG のエラーが消えない**：電池の入り口（コネクタのネット）と GND に PWR_FLAG。

## 発展課題

1. タクトスイッチで ON/OFF できるソフトスイッチを足す（[3-3](../part3-power/3-3-protection.md) もっと深く）。ただし非常停止として必ず切れること。
2. 2 A 以上出せる降圧 DC-DC を、データシートの例どおりに描く。
