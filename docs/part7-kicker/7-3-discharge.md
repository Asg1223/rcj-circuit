# 7-3 放電の回路

## ねらい

- N チャネル MOSFET でソレノイドに電流を流す回路を描ける
- フライバックダイオードが必要な理由を説明できる

## 回路

```
HV ──┬────────────── ソレノイド（＋）
     │
    D2（K が HV、A が SOL_N）
     │
SOL_N ──┴──────────── ソレノイド（−）
     │
     D
     Q3（N ch、100 V、ロジックレベル）G ── 100 Ω ── KICK（マイコン）
     S                                  │
     │                                 10 kΩ（プルダウン）
GND ─┴──────────────────────────────────┴── GND
```

- **Q3**：ローサイドスイッチ（[1-5](../part1-basics/1-5-mosfet.md)）。KICK を H にすると、ソレノイドに電流が流れます。
- **10 kΩ のプルダウン**：マイコンの起動中やケーブルが抜けたとき、**勝手に蹴らない**ために必ず付けます。
- **100 Ω**：ゲートに流れる一瞬の電流からマイコンを守ります。

### フライバックダイオード

コイル（ソレノイド）は、電流を急に止めようとすると、高い電圧を出して電流を流し続けようとします。Q3 を OFF にした瞬間、SOL_N に HV よりはるかに高い電圧が出て、Q3 を壊します。

D2 があると、その電流は D2 を通って HV にもどり、電圧が上がりません。ダイオードは、

- 逆電圧が HV より十分高い（200 V 品など）
- 速く切りかわる（ファストリカバリー、ショットキーなど）
- 一瞬の大電流に耐える

ものを選びます。教材は ES3D（200 V・3 A のファストリカバリー）を例にしています。

## パルスの長さ

KICK を H にする時間で、蹴る強さが変わります。

```cpp
void kick(int ms) {
  digitalWrite(A3, LOW);     // 充電を止める（CHG_EN）
  digitalWrite(A1, HIGH);    // KICK
  delay(ms);                 // 10〜30 ms くらいから試す
  digitalWrite(A1, LOW);
  digitalWrite(A3, HIGH);    // 充電を再開
}
```

!!! tip "長すぎても強くならない"
    コンデンサの電気はすぐになくなるので、ある長さより長くしても強くなりません。逆に、ずっと ON にすると、昇圧モジュールの電流が流れ続けてソレノイドが熱くなります。プログラムで**最大の時間を決めて**おきます。

## チェック問題

1. フライバックダイオードの向き（K と A）はどちらですか。
2. Q3 のゲートのプルダウンを付け忘れると、どんな危険がありますか。

??? success "答え"
    1. カソード（K）を HV 側、アノード（A）を SOL_N（MOSFET のドレイン）側。ふだんは電流が流れない向き。
    2. マイコンの起動中などにゲートが浮いて、勝手に蹴る。
