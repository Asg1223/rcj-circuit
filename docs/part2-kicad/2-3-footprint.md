# 2-3 フットプリントの割り当て

## ねらい

- 回路図のシンボルに、正しいフットプリントを割り当てられる
- 標準ライブラリにない部品のシンボル・フットプリントを作る手順を言える

## 理論

シンボル（回路図の記号）だけでは、基板の上でどの形になるかが決まりません。**フットプリント**を割り当てて、初めて基板に部品が出てきます。

同じ「10 kΩ の抵抗」でも、フットプリントはいろいろです。

| フットプリント | 大きさ | 手はんだ |
|---|---|---|
| `Resistor_THT:R_Axial_DIN0207_L6.3mm_D2.5mm_P7.62mm_Horizontal` | 足のある抵抗 | とても楽 |
| `Resistor_SMD:R_1206_3216Metric` | 3.2 × 1.6 mm | 楽 |
| `Resistor_SMD:R_0805_2012Metric` | 2.0 × 1.25 mm | 少し練習がいる |
| `Resistor_SMD:R_0603_1608Metric` | 1.6 × 0.8 mm | むずかしい |

教材の基板は、手はんだを考えて **0805 以上**にしています。

## 手を動かす：割り当てる

1. 回路図エディタで「ツール → フットプリントを割り当て」を開きます。
2. 左に「ライブラリ」、中に「シンボル」、右に「フットプリント」の一覧が出ます。
3. 中の R1 を選び、右の一覧から `Resistor_SMD:R_1206_3216Metric` をダブルクリックします。
4. 全部の部品に割り当てたら「適用して保存」を押します。

| 部品 | H1 で使うフットプリント |
|---|---|
| J1 | `Connector_JST:JST_XH_B2B-XH-A_1x02_P2.50mm_Vertical` |
| D1 | `Diode_SMD:D_SMA` |
| SW1 | `Button_Switch_THT:SW_DIP_SPSTx01_Slide_9.78x4.72mm_W7.62mm_P2.54mm` |
| R1, R2 | `Resistor_SMD:R_1206_3216Metric` |
| D2, D3 | `LED_SMD:LED_1206_3216Metric` |
| H1, H2 | `MountingHole:MountingHole_3.2mm_M3` |

!!! warning "ピン番号と極性を確かめる"
    フットプリントのパッド番号と、シンボルのピン番号が対応します。LED やダイオードは「1 番がカソード（K）」が KiCad の標準ですが、コネクタや一部の部品では、**シルクの「+」と 1 番ピンが逆**のことがあります（XT30 の例：[1-6](../part1-basics/1-6-datasheet.md)）。フットプリントエディタで開いて、パッド番号とシルクを確かめてください。

## 標準にない部品を作る

### シンボル

1. 「ツール → シンボルエディター」を開きます。
2. 「ファイル → 新規ライブラリ」でプロジェクト用のライブラリを作ります（例：`kicad/lib/rcj.kicad_sym`）。
3. 「新規シンボル」で名前を付け、データシートのピン配置どおりにピンを置きます（++p++）。
4. ピンの**種類（電気的タイプ）**を正しく選びます。電源入力は Power input、出力は Output、未使用は Not connected。ERC はこの種類を見て調べます。

### フットプリント

1. 「ツール → フットプリントエディター」を開きます。
2. データシートの **Recommended Land Pattern（推奨ランドパターン）** の寸法でパッドを置きます。
3. 部品の外形を F.Fab に、目印を F.Silkscreen に、部品が占める範囲を F.Courtyard に描きます。
4. 1 番ピンの目印（●や三角）を必ず入れます。

!!! tip "まず探す"
    自分で作る前に、標準ライブラリで似た形（同じパッケージ）を探しましょう。「SOT-23」「SOIC-8」のようなパッケージ名で検索すると、たいてい見つかります。ピン配置だけ違うなら、シンボルだけ作ればよいことが多いです。

## チェック問題

1. 同じ回路図で、抵抗を 0805 から 1206 に変えたいとき、どこを直しますか。
2. 自作フットプリントで 1 番ピンの目印を忘れると、何が困りますか。

??? success "答え"
    1. フットプリントの割り当て（シンボルのプロパティの「フットプリント」）。直したら ++f8++ で基板に反映します。
    2. 実装するとき向きがわからず、IC を逆向きに付けてしまうおそれがある。
