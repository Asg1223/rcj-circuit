# H4 メイン基板

**時間の目安：4 時間**　｜　対応：[第4部](../part4-mcu/index.md)

## ステップ

- [ ] 使うマイコン（ボード）を決め、ピンの機能（UART・SPI・I2C・PWM・アナログ専用）を表にする
- [ ] つなぐもの（電源・IR リング・モータ・キッカー・IMU・カメラ・審判モジュール）を表にして、ピンが足りるか数える
- [ ] 基板の上でのコネクタの位置を、ロボットの中の配置（[8-4](../part8-system/8-4-layout.md)）から決める
- [ ] コネクタの位置を見て、**配線が交差しにくいようにピンを割り当てる**（[4-6](../part4-mcu/4-6-main-board.md)）
- [ ] 3.3 V の相手にはレベル変換を入れる（[4-2](../part4-mcu/4-2-level.md)）
- [ ] 審判モジュールの入力に、直列抵抗とプルダウン（[4-5](../part4-mcu/4-5-debug.md)）
- [ ] 回路図の ERC を 0 に
- [ ] 基板：USB が外から挿せる向きに置く
- [ ] 配線し、交差するところは裏で
- [ ] DRC を 0 に
- [ ] コネクタのピン表を、電源基板・モータ基板の表と見くらべる

## 合格条件

| 項目 | 目安 |
|---|---|
| ERC・DRC のエラー | 0 |
| ビアの数（GND 以外） | 10 個以下（ピンの割り当てがうまいほど少ない） |
| USB | 3D ビューアで、ケーブルが挿せる |
| ピン表 | 相手の基板とすべて一致 |

## 困ったとき

- **ピンが足りない**：IR リングをシフトレジスタにする、ラインセンサをサブマイコンにする、ピンの多いマイコンにする（[8-1](../part8-system/8-1-split.md)）。
- **配線がからまる**：ピンの割り当てを変える。コネクタのピンの順番を変える（相手の基板も一緒に）。

## 発展課題

1. Arduino Nano ESP32（3.3 V）を載せる前提で、レベル変換をどこに入れるか考えなおす。
2. ピンの多いマイコン（Raspberry Pi Pico など）で、ラインセンサを 4 本以上読めるようにする。
