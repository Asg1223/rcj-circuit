# 6-2 H ブリッジとドライバ IC

## ねらい

- H ブリッジで回転の向きを変えるしくみを説明できる
- モータに合うドライバ IC を選べる

## 理論

### H ブリッジ

スイッチ 4 個を「H」の形に並べ、モータにかける電圧の向きを変えます。

```
VBAT ──┬───────────┬──
       S1          S3
       ├── モータ ──┤
       S2          S4
GND ───┴───────────┴──
```

| ON にするスイッチ | モータ |
|---|---|
| S1 と S4 | 正転 |
| S3 と S2 | 逆転 |
| S2 と S4（下 2 つ） | ブレーキ（両端をショート） |
| 全部 OFF | 空転（惰性で回る） |
| S1 と S2（同じ側の上下） | **電源のショート！**（絶対にだめ） |

自分で MOSFET を 4 個並べて作ることもできますが、「同じ側の上下が同時に ON にならないようにする」「ゲートを速く動かす」「熱・電流の保護」など、気をつけることがたくさんあります。最初は**ドライバ IC** を使いましょう。

### ドライバ IC の選び方

| 項目 | 見る値 | 教材の DRV8871 |
|---|---|---|
| モータ電源の電圧 | 電池の満充電より上 | 6.5〜45 V |
| 電流 | ピーク・連続 | ピーク 3.6 A |
| 電流制限 | あると安心 | 抵抗 1 本で設定できる |
| 保護 | 過熱・過電流・低電圧 | すべてあり |
| 入力 | PWM の線の数、ロジックの電圧 | IN1・IN2 の 2 本。3.3 V・5 V どちらも可 |
| パッケージ | 手はんだできるか、放熱 | HSOP-8（裏に放熱パッド） |

ほかによく使われる例：TB67H450FNG（東芝。秋月電子のモジュールあり）、DRV8874、VNH5019 など大電流用。どれも**データシートの推奨回路と放熱の指示**を守ることが大事です。

!!! tip "放熱パッドのはんだ付け"
    HSOP-8 のように裏に放熱パッドがある部品は、こてだけでは裏のパッドがはんだ付けできません。基板の裏から穴（サーマルビア）にはんだを流しこむか、ホットエアー・ホットプレートを使います（[9-2](../part9-build/9-2-solder.md)）。

## DRV8871 の動き

| IN1 | IN2 | OUT1 | OUT2 | モータ |
|---|---|---|---|---|
| 0 | 0 | 開放 | 開放 | 空転（1 ms 続くと省電力モード） |
| 0 | 1 | L | H | 逆転 |
| 1 | 0 | H | L | 正転 |
| 1 | 1 | L | L | ブレーキ |

## チェック問題

1. H ブリッジで、同じ側の上と下のスイッチを同時に ON にするとどうなりますか。
2. ブレーキと空転のちがいは何ですか。

??? success "答え"
    1. 電源から GND へ直接ショートして、大電流が流れ壊れる（シュートスルー）。
    2. ブレーキはモータの両端をつないで急に止める。空転は何もつながず惰性で回る。
