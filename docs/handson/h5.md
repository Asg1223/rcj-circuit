# H5 IR リング基板

**時間の目安：3 時間**　｜　対応：[第5部](../part5-sensors/index.md)

!!! warning "自分のチームのセンサの情報"
    使う受光モジュールの型番や個数を公開したくないときは、この課題をチーム用の非公開リポジトリで進めます。公開リポジトリには `.private-words` で止める仕組みがあります（[付録](../appendix/team-repo.md)）。

## ステップ

- [ ] 受光モジュールのデータシートで、ピン配置と推奨回路（R・C の値）を確かめる（[5-1](../part5-sensors/5-1-ir-receiver.md)）
- [ ] 読み方（直接・74HC165・サブマイコン）を決める（[5-2](../part5-sensors/5-2-many-inputs.md)）
- [ ] 回路図を描き、受光モジュールの電源（抵抗の後）に PWR_FLAG を付ける
- [ ] ERC を 0 に
- [ ] 円形の外形を描く（[5-3](../part5-sensors/5-3-ir-ring.md)）
- [ ] 受光モジュールを、計算した座標と角度に置く（ドームが外向き）
- [ ] R・C を各モジュールのすぐ内側に
- [ ] 表に +5V のリング、裏に放射状の出力
- [ ] センサの番号と入力の番号の対応表を作る
- [ ] DRC を 0 に

## 合格条件

| 項目 | 目安 |
|---|---|
| ERC・DRC のエラー | 0 |
| センサの角度のずれ | 設計値どおり（座標を数字で入れる） |
| C と受光モジュールの距離 | 5 mm 以内 |
| 対応表 | プログラムに書ける形になっている |

## 困ったとき

- **座標の計算がめんどう**：スプレッドシートで $x = c_x + r\sin\theta$、$y = c_y - r\cos\theta$ を計算してから入れる。
- **放射状の配線が中心でぶつかる**：チップの向きと、センサ → 入力の対応を変える（プログラムで並べかえればよい）。

## 発展課題

1. 74HC165 を 2 個にして 16 個の受光モジュールにする。
2. リング基板に小さなマイコンを載せて、UART で「受光時間の割合」を送る形にする。
