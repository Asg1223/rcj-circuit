# 4-1 ボードを載せるか、チップを載せるか

## ねらい

- マイコンを基板に載せる 3 つの方法と、それぞれのよい点・悪い点を言える

## 3 つの方法

| 方法 | 例 | よい点 | 悪い点 |
|---|---|---|---|
| **開発ボードを載せる** | Arduino Nano、Teensy、ESP32-DevKitC、Raspberry Pi Pico | USB・電源・水晶が入っている。壊れたら差しかえ | 大きい、重い。ピン配置がボードで決まる |
| **モジュールを載せる** | ESP32-S3-WROOM-1 | 無線の部分ができている。小さい | USB・電源・リセットの回路は自分で作る |
| **チップを直接載せる** | STM32、RP2040、ATmega328P | 一番小さい、自由 | 水晶・電源・書き込みの回路を全部作る。はんだ付けがむずかしい |

教材のメイン基板は、**Arduino Nano と同じ形の開発ボード**を、ピンソケットで載せる形にしています。

- 中高生でもはんだ付けしやすい（ピンソケットは足のある部品）
- 試合中に壊れても、ボードだけ差しかえられる
- 同じ足の配置のボード（Nano Every、Nano ESP32 など）に変えられる

!!! warning "同じ形でも電圧が違う"
    Arduino Nano（ATmega328P）と Nano Every は 5 V で動きますが、Nano ESP32 は **3.3 V** で動きます。同じ基板に載せかえるときは、ほかの基板とつながるピンの電圧を確かめてください（[4-2](4-2-level.md)）。

## マイコン選びで見ること

| 項目 | サッカーロボットで必要な目安 |
|---|---|
| PWM の数 | モータ 4 個なら 4 本以上（向きの信号は普通の出力でよい） |
| アナログ入力 | 電池電圧、ラインセンサ、キッカーの電圧など |
| SPI・I2C・UART | IR リング（SPI）、IMU（I2C）、CoreS3（UART） |
| 計算の速さ | 機械学習の推論をするならメモリと速さに余裕を（[機械学習教材 第4部](https://asg1223.github.io/rcj-soccer-ml/)） |
| ピンの数 | 足りなくなりやすい。[4-6](4-6-main-board.md) のように表にして数える |

## チェック問題

1. 試合中にマイコンが壊れたとき、すぐに直しやすいのはどの方法ですか。
2. Nano ESP32 を、5 V の信号を出す基板とそのままつないでよいですか。

??? success "答え"
    1. 開発ボードをソケットで載せる方法。
    2. よくありません。ESP32 の入力は 3.3 V までなので、レベル変換が必要です。

??? example "もっと深く：チップを直接載せる"
    RP2040 や STM32 を直接載せると、メイン基板を小さく軽くできます。必要なのは、電源（パスコンを各電源ピンに）、水晶（またはクロック）、リセット回路、書き込み用の端子（SWD や USB）です。メーカーの「ハードウェア設計ガイド（Hardware design with RP2040 など）」に、最小の回路と基板の例があります。最初の 1 枚はそれをそのまままねるのが近道です。
